# 🐾 Petshop Database Management System

GUI-приложение для управления базой данных магазина домашних животных, разработанное в рамках лабораторной работы по курсу "Визуализация данных".

##  Функциональность
- **Управление данными**: просмотр, добавление, удаление записей
- **5 связанных таблиц**: customers, goods, suppliers, purchases, sales
- **Визуализация**: графики цен закупок и продаж
- **Аналитика**: поиск максимальной цены, статистика

##  Технологии
- **Python 3.10+**
- **SQLite** (встроенная БД)
- **PyQt6** (графический интерфейс)
- **Matplotlib** (визуализация данных)
